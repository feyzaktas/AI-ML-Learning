**EN:** This section contains practical exercises and learning notes on unsupervised machine learning algorithms used to discover patterns and structures in unlabeled data.

**TR:** Bu bölüm, etiketlenmemiş verilerde örüntüleri ve yapıları keşfetmek için kullanılan denetimsiz makine öğrenmesi algoritmalarına ait uygulamaları ve öğrenme notlarını içerir.

- Principal Component Analysis (PCA) | Temel Bileşen Analizi

## Purpose | Amaç

**EN:** To explore clustering algorithms and understand how unsupervised learning can reveal hidden patterns in data.

**TR:** Kümeleme algoritmalarını incelemek ve denetimsiz öğrenmenin verilerdeki gizli örüntüleri nasıl ortaya çıkardığını anlamak.
